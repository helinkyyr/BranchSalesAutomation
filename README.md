🏢 Branch Sales Automation

Modern arayüze sahip şube satış ve stok takip otomasyonu.
Bu proje C#, Windows Forms, Entity Framework ve SQL Server kullanılarak geliştirilmiştir.



🚀 Proje Hakkında

Branch Sales Automation; ürün, stok, satış ve raporlama işlemlerini tek merkezden yönetmek amacıyla geliştirilmiş modern masaüstü otomasyon sistemidir.

Projede:

* şube bazlı stok kontrolü,
* satış işlemleri,
* dashboard yapısı,
* grafik destekli raporlama,
* kritik stok uyarıları
  gibi özellikler bulunmaktadır.
